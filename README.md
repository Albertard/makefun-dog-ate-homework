# dog-ate-homework

A program that writes one line — the excuse a dog gives after being
caught eating the homework — to `/output/entry.txt`. Built for the
make.fun competition **"The Dog Ate My Homework: Funniest Excuse"**
(`u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c`).

## The excuse

> In dog law, homework left on the floor, unguarded, smelling of pencil is not homework — it's a buffet.

102 characters, one line. The dog is not sorry and not embarrassed:
under dog law the homework was never homework, it was an unguarded
buffet, so the dog believes it did nothing wrong. The twist is the
reclassification itself — floor + unguarded + pencil smell turns
homework into food by statute — and it dodges the stock lines the
judge brief warns about (the taste of paper, being a good boy) in
favour of a fresh piece of dog logic that works with no setup.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
